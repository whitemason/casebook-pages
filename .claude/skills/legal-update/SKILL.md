# 처리방침 · 약관 바꾸기

## 1. 바꿔도 되는지 확인하기

- 운영자의 승인(사용자 결정)이 있어야 해요.
- 이미 정한 사항(예: 처리방침 맨 위 요약 문장 유지)과 어긋나면 반영하지 말고 알려요.

## 2. 고치기

1. `git pull --ff-only`
2. 받은 문장을 그대로 넣어요. 처리방침은 합니다체, 약관은 해요체예요.
3. 약관이면 앱 원문 `CasebookTerms.swift`(casebook-service-appleos)와 조 제목 · 문장을 하나씩 대조해요. 상수(`CaseReview.maxBodyLength`, `AccountDeactivation.retentionMonths`, `supportEmail`)는 앱 값으로 넣어요.
4. 조나 장이 늘거나 줄면 `toc` 목록과 `<h2 id>`를 함께 맞춰요. 처리방침 `p1`~`p12` 앵커는 바꾸지 않아요.
5. 시행일을 바꾸면 모든 곳을 함께 바꿔요.
   - 처리방침: 머리 줄, 첫머리 안내 줄("이 방침은 … 부터 시행합니다. 바뀐 곳: …"), 바닥 줄
   - 약관: 머리 줄(판 표시 포함), 바닥 줄
6. 시행일 규칙(처리방침 12장): 시행 7일 전부터 알려요. 중요한 변경은 30일 전. 보관 기간을 줄이는 정정이나 연락처 같은 표기는 운영자가 정하면 시행일 · 판을 그대로 둬요.
7. `git diff --word-diff`로 바뀐 곳이 요청과 정확히 같은지 봐요.

## 3. 공개하고 확인하기

1. `npm run build`가 경고 없이 성공하는지 봐요.
2. 커밋 → 푸시 직전 `git pull --ff-only` → 푸시
3. 실제 사이트(`https://casebook.whitemason.club/privacy.html` · `terms.html`)에서 새 문장이 보이고 옛 문장이 0곳인지, 시행일 표시가 맞는지 확인해요.
4. 바뀐 문장 전/후, 시행일, 커밋 번호를 알려요. 앱이나 다른 문서와 어긋나는 곳이 보이면 함께 알려요.
