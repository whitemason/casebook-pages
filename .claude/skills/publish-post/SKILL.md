# 블로그 글 공개하기

## 1. 넣기

1. `git pull --ff-only`
2. 원고를 `src/content/blog/<영문-kebab-case>.md`로 넣어요. 파일 이름이 주소가 돼요. 넘겨받은 원고는 문장 그대로 넣고, `cmp`로 원본과 같은지 확인해요.
3. 커버(작업 기록 · 릴리스 노트): `src/assets/images/`에 넣고 머리말 `cover`와 이름을 맞춰요. 개발일지는 `cover`를 비워요.
4. 본문 그림: 넣기 전에 그림을 열어 봐요. 밝은 · 어두운 쌍이 같은 내용인지, 엉뚱한 그림이 섞이지 않았는지 확인해요. 폭 4400px 같은 큰 그림은 `sips --resampleWidth 2200`으로 줄여요. 이름 끝 `-light` · `-dark`를 지켜요.

## 2. 점검하기 (고치기 전에 알리기)

- 공개하면 안 되는 것(AGENTS.md)이 없는지 봐요. 특히 출시 앱의 보호 장치 동작, 내부 이름, 개인 정보.
- 끝나지 않은 일을 끝났다고 쓰지 않았는지 봐요.
- 처리방침과 어긋나는 사실(정보를 어디에 쓰는지, 누구에게 보이는지)이 있으면 알려요.
- 규칙에 걸리면 문장을 고치기 전에 알려요. 승인 뒤에 고쳐요.

## 3. 공개하기

1. `npm run build`가 경고 없이 성공하고, 그림 경로가 `-light` · `-dark` 이름 그대로 나오는지 봐요.
2. 커밋 → 푸시 직전 `git pull --ff-only` → 푸시
3. 확인
   - `https://casebook.whitemason.club/blog/<이름>.html` 200, 블로그 목록에 보임
   - 밝은 모드에서는 라이트 그림만, 다크 모드에서는 다크 그림만 보임
   - 휴대폰 폭(375px)에서 페이지가 옆으로 밀리지 않음

## 4. 알리기

글 주소, 블로그 목록 확인, 커밋 번호, 점검에서 본 것을 알려요.
